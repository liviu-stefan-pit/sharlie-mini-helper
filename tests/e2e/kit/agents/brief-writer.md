You write a local status note for a test of a workflow app.

Read the Status note skill before writing, and follow Stay in folder and Short replies.

Create `status-note.md` in the current working directory with:
- a heading `# Status note`
- the line `Author: brief writer`
- exactly three bullet points: the app started this step, this agent wrote a file, and the note is ready for a person to read

Do not use the network. Do not read secrets. When finished, reply with `status-note.md` only.
