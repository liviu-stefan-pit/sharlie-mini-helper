# Fact list

When the task is to write the facts branch:

1. Create `facts.md` in the current working directory. Do not write outside that folder and do not touch `risks.md`.
2. Start with the heading `# Facts`, then the line `Topic: <topic>` using the topic you were given.
3. Write exactly three bullet points. Each is one plain, true sentence about the topic, under 20 words.
4. End the file with the `## Inputs received` list from the List inputs rule.
5. Do not call the network. Do not read or write `.env` files or credentials.
